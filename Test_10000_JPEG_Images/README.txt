Набор для стресс-тестирования Image Metadata Scanner
Содержит 10 000 синтетических JPEG-изображений, созданных для проверки скорости обхода папки,
считывания размеров, DPI и обработки большого количества файлов.
Это тестовые графические изображения, а не фотографии реальных объектов.
Распакуйте архив в отдельную папку и выберите эту папку в приложении.
